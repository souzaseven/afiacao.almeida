# ✂️ Afiação Almeida - Especialista em Afiação de Equipamentos de Manicure

<img src="https://github.com/souzaseven/afiacao.almeida/blob/Desafios/afiacaoalmeidabanner.png?raw=true" width="70%" alt="Preview">

Serviço profissional de afiação de alicates e equipamentos de manicure, garantindo precisão e durabilidade para seus instrumentos.

## ✨ Funcionalidades

- **Agendamento online** de serviços
- **Visualização ampliada** das imagens de antes/depois
- **Formulário de contato** direto para WhatsApp
- **Horários de atendimento** em formato de calendário interativo
- **Links diretos** para redes sociais

## 🛠 Tecnologias
Tecnologias principais:
- HTML5 semântico
- CSS3 Flexbox/Grid
- JavaScript (ES6)
- Google Fonts (Poppins)

🚀 Como Usar <br>
Navegue pelas seções:<br>
Home: Apresentação do serviço<br>
Horários: Calendário de atendimento<br>
Galeria: Fotos dos trabalhos<br>
Contato: Formulário e informações<br>
Utilize o botão flutuante do WhatsApp para contato rápido
